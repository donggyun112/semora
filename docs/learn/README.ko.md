# Semora를 이해하는 순서

이 자료는 Python 코드를 읽을 수 있지만 에이전트 프레임워크와 Semora는 처음인 사람을 위한 학습 과정이다.
문서를 처음부터 끝까지 외우는 대신, 작은 동작을 이해하고 그것을 구현하는 코드로 내려간다.

각 장은 **문제 → 코드 → 실행 과정 → 설계 이유 → 확인 질문** 순서로 읽는다.
질문의 답도 같은 장에 있으므로 혼자 계속 읽을 수 있다.

## 실행 준비

저장소 루트에서 실행한다.

```bash
uv sync --dev
```

“독립 실행 예제”라고 표시한 Python 블록은 각각 별도의 `.py` 파일에 저장해서 실행할 수 있다.

```bash
uv run python 파일경로.py
```

학습 예제는 실제 LLM API를 호출하지 않는다. 모델 응답을 정한 테스트용 모델을 사용한다.
“부분 코드”는 설명을 위해 일부만 보여 주는 것으로, 단독 실행용이 아니다.

## 읽는 동안 구분할 세 가지

- **모델이 요청한 것**: 도구 이름과 인자.
- **프로그램이 한 것**: 정책 검사와 실제 Python 함수 실행.
- **저장소에 확인된 것**: 시작 기록, 완료 결과, 재개에 필요한 정보.

“모델이 완료했다고 말했다”와 “도구가 성공했고 결과가 기록됐다”를 구분하면 복구 장이 쉬워진다.

이 자료는 작성 당시 체크아웃의 코드와 테스트를 기준으로 한다. 특히 사람의 거절 처리와 예제의 권한 선택 방식은 현재 구현을 따른다.
API를 찾을 때는 [API.md](../API.md), 동작을 확인할 때는 각 장에 연결한 테스트를 함께 본다.
